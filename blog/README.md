### ⚠️ 페이지 URL — 블로거는 페이지에 커스텀 퍼머링크를 제공하지 않는다
글(포스트)에만 "권한 링크"가 있고 **페이지는 제목에서 URL이 자동 생성**된다.
한글 제목으로 게시하면 `/p/blog-page.html` 처럼 나와 페이지 간 링크가 깨진다.

**우회법**: 영문 제목으로 먼저 게시해 URL을 고정한 뒤 제목만 한글로 바꾼다.
블로거는 최초 게시 시점에 URL을 확정하고, 이후 제목을 바꿔도 URL은 유지된다.
```
제목 "about" 으로 게시 → /p/about.html 확정 → 제목을 「소개」로 수정
제목 "privacy" 로 게시 → /p/privacy.html 확정 → 제목을 「개인정보처리방침」으로 수정
제목 "contact" 로 게시 → /p/contact.html 확정 → 제목을 「연락처」로 수정
```

## 글 쓰는 흐름 (가격비교 포스트)

```
① 확장 클로드로 수집        collect_prompt.md 프롬프트 → JSON
② JSON 을 저장              posts_data/<카테고리>.json
③ 제휴 링크 채우기          각 item 에 "links": {"toss":"...", "coupang":"..."}
④ 생성                      python3 tools/make_blogpost.py posts_data/<카테고리>.json
⑤ blog/posts/<카테고리>.html 을 블로거에 "HTML 보기"로 붙여넣기
```

- **링크가 비어 있어도 생성된다.** 해당 버튼은 "링크 준비 중" 비활성 상태로 나오므로
  잘못된 곳으로 유입될 일은 없다. 링크를 받은 뒤 다시 생성하면 된다.
- 실행하면 **제휴 링크 미입력 상품**과 **토스 쉐어링크 발급 불가 상품**(수익 0원)을 경고로 알려준다.
- 글 자체는 `tools/blogpost_template.html`(레이아웃·CSS)과 `tools/make_blogpost.py`(문구·표) 로 나뉜다.
  디자인은 템플릿, 문장은 파이썬 쪽을 고친다.

### 글 구조가 이렇게 된 이유
- **가격은 매일 바뀌고 자동 수집이 불가능**하다(쿠팡·토스 모두 이 세션에서 접근 불가).
  그래서 금액은 확인 날짜와 함께 적되, 글의 본체는 **"어떤 상황이면 어디가 유리한가"** 로 짰다.
  가격이 바뀌어도 글이 죽지 않게 하기 위한 구조다.
- **가격·배송·혜택 3축**으로 비교한다. 쿠팡이 비싸도 로켓배송으로 이기는 경우가 많아,
  가격만 비교하면 독자가 현실과 다르다고 느낀다.
- 효능은 **제조사 표기 인용만** 한다. 단정하면 표시광고법 문제가 된다.
- 하단에 **"직접 사용해 본 후기가 아니라 비교 가이드"** 라고 명시한다.
  안 써본 걸 써본 척하는 것보다 신뢰와 검색 평가 양쪽에 낫다.

## ★ 토스쇼핑에서 수집하는 게 더 빠르다 (2026-07-29 발견)

토스쇼핑 앱에 두 기능이 있어, **쿠팡·토스 데이터를 앱 하나에서 모을 수 있다.**

### 1) 판매 순위
`카테고리 → OO 판매 순위` — "최근 30일간 많이 팔린 순위".
**토스는 후기가 얇은 게 약점인데, 판매 순위가 그걸 메운다.** 후기 2건짜리도
"판매 6위"라면 아무도 안 산 물건은 아니라는 신호가 된다. 글에서 후기와 함께 제시할 것.

### 2) 가격 비교하기
상품 상세의 **`가격 비교하기`** 버튼 → 네이버·11번가·**쿠팡**·G마켓·롯데ON 탭.
쿠팡 탭을 누르면 **그 상품명으로 검색한 쿠팡 결과가 그대로** 뜬다.

⚠️ **정확한 동일 상품 매칭이 아니라 상품명 검색이다.** 이름이 미묘하게 다른 경우가 많으니
(토스 "회전형 반자동 급식기 세트" vs 쿠팡 "회전형 반자동 올인원 급식기")
같은 모델이라고 단정하지 말 것. 그래도 **양쪽 시세를 한 화면에서 보는 용도로는 충분**하다.

### 그래서 수집 순서가 이렇게 바뀐다
```
① 토스 판매 순위에서 상품 후보 확보 (순위 = 신뢰 신호)
② 각 상품 상세에서 가격·적립·배송 캡처
③ '가격 비교하기 → 쿠팡' 으로 쿠팡 시세까지 같은 화면에서 캡처
④ 쿠팡에서 살 제품은 따로 들어가 상품평 캡처 (후기 기반 장단점용)
```
쿠팡을 먼저 훑고 토스를 뒤지던 기존 순서보다 손이 덜 간다.

### ⚠️ 순위표를 그냥 믿으면 안 되는 이유
자동급식기 판매 1위가 **"펫꾸러기 회전형 반자동"** 이었다. 이름에 반자동이라고 적혀 있고
중력식이라 **정해진 시간에 정량을 주지 못한다.** "자동급식기"로 검색해 산 사람 상당수가
사실 반자동을 사고 있다는 뜻이다.
→ 순위는 후보 발굴에만 쓰고, **제품 유형은 상품명·사양에서 따로 확인**할 것.
→ 이 함정 자체가 좋은 글감이라 「고를 때 볼 것」 첫 항목으로 넣었다.
