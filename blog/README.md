# 블로그(어디사) 원고 저장소

- 전략은 `../PLAN.md` 참고

## pages/ — 필수 페이지 3개

블로거에 **글(Post)이 아니라 페이지(Page)** 로 올린다.
`페이지 → 새 페이지 → 우측 상단 연필 아이콘 → HTML 보기` 에서 통째로 붙여넣기.

| 파일 | 페이지 제목 | 권장 주소(끝부분) |
|---|---|---|
| `about.html` | 소개 | `about` |
| `privacy.html` | 개인정보처리방침 | `privacy` |
| `contact.html` | 연락처 | `contact` |

블로거 페이지 주소는 `https://eodisanow.blogspot.com/p/<주소>.html` 형태가 된다.
세 파일이 서로 `/p/privacy.html`, `/p/contact.html` 로 링크하고 있으므로 **주소를 위 표대로 맞춰야** 링크가 살아난다.

### 올리기 전에 반드시 바꿀 것
1. **`여기에_본인_이메일_주소`** → 실제 이메일 (privacy.html 1곳, contact.html 1곳)
   - 개인 메일을 그대로 노출하면 스팸이 붙는다. **문의 전용 주소를 따로 파는 걸 권장.**
2. **privacy.html 맨 아래 `2026년 0월 0일`** → 실제 시행일(=페이지를 공개하는 날)

### 올린 뒤
- `설정 → 레이아웃` 에서 페이지 가젯을 추가해 3개 페이지를 하단 메뉴에 노출 (애드센스 심사 시 접근성 확인용)

## ⚠️ 개인정보처리방침에 대하여
`privacy.html` 은 **Blogger 로 운영하는 제휴 블로그의 일반적인 상황을 전제로 작성한 초안**이며 법률 자문이 아니다.
개인정보처리방침은 **실제 처리 내용과 일치해야** 하므로, 아래가 달라지면 본문도 함께 고쳐야 한다.

- Google Analytics·Search Console 외의 분석 도구를 붙였을 때
- 애드센스 외 다른 광고 네트워크를 붙였을 때
- 뉴스레터·문의 폼 등 **개인정보를 직접 입력받는 기능**을 추가했을 때 (이 경우 수집 항목·동의 절차를 반드시 추가)
- 제휴처가 늘어났을 때 (5항 수정)

현재 초안은 "회원가입 없음 / 직접 입력받는 개인정보 없음"을 전제로 한다.
