# 브라우저 클로드용 상품 수집 프롬프트

> Claude Code(이 세션)는 쿠팡·토스쇼핑에 접근할 수 없다(403, 브라우저도 차단).
> 대신 **크롬 확장 클로드**가 사용자의 로그인된 브라우저에서 수집한다.
> 아래를 복사해 `<>` 부분만 바꿔서 확장 클로드에게 준 뒤, 받은 JSON을 그대로 이 세션에 붙여넣으면 된다.

---

## 복사해서 쓸 프롬프트

```
쿠팡과 토스쇼핑에서 "<자동급식기>" 상품을 조사해줘.

【대상】
두 쇼핑몰 모두에서 판매 중인 상품 위주로 5개. 가격대를 섞어줘:
- 저가 1~2개 (3~5만원대)
- 중간 2개 (8~15만원대)
- 고가 1개 (20만원 이상)

【각 상품마다 확인할 것】
1. 정확한 상품명 (판매 페이지에 표기된 그대로)
2. 제조사 / 모델명
3. 쿠팡 가격 + 로켓배송 여부 + 리뷰 수 + 평점
4. 토스쇼핑 가격 + 배송 조건(무료/유료, 예상 도착일)
   - 토스쇼핑에 없으면 null
   - 상품 상세에서 "쉐어링크 공유하기" 버튼이 보이는지도 알려줘
5. 핵심 사양
   - 용량(리터)
   - 급여 방식 (건사료 전용 / 습식 가능)
   - 전원 (어댑터 / 배터리 / 겸용) — 정전 대비 되는지 중요
   - 앱 연동 여부
   - 카메라 유무
   - 세척 (급여통·통로 분리세척 가능한지)
   - 소음 표기값 (있으면)
6. 상품 페이지 URL (일반 URL. 제휴 링크 아님)

【중요】
- 가격은 "오늘 날짜" 기준으로 적고, 쿠폰 적용 전/후가 다르면 둘 다 적어줘
- 같은 모델인지 확실하지 않으면 "확인 불가"라고 적어줘. 추측하지 말 것
- 광고/스폰서 상품은 제외
- 효능 관련 표현(살균, 탈취 등)은 제조사 표기를 그대로 인용만 하고 판단하지 말 것

【출력 형식】
아래 JSON 형식 그대로. 설명 문장 없이 JSON만.

{
  "category": "<자동급식기>",
  "checked_at": "2026-00-00",
  "items": [
    {
      "name": "",
      "brand": "",
      "model": "",
      "coupang": { "price": 0, "rocket": true, "reviews": 0, "rating": 0.0, "url": "" },
      "toss":    { "price": 0, "shipping": "", "sharelink_available": true, "url": "" },
      "spec": {
        "capacity_l": 0,
        "wet_food": false,
        "power": "",
        "blackout_backup": false,
        "app": false,
        "camera": false,
        "washable": "",
        "noise_db": null
      },
      "note": ""
    }
  ]
}
```

## 받은 뒤 이 세션에서 할 일
1. JSON 을 그대로 붙여넣기
2. → `products/<id>.json` 의 블로그 블록으로 변환
3. → 비교표·본문·FAQ 가 들어간 블로거용 HTML 생성

## 제휴 링크는 별도
위 프롬프트는 **일반 상품 URL** 만 받는다. 실제 수익 링크는 사용자가 직접 발급해야 한다.
- 쿠팡: 파트너스에서 딥링크 생성
- 토스: 앱 상품 상세 → 공유 → **"쉐어링크 공유하기"** (일반 "공유하기"는 수익 0원)

## ⚠️ 확장 클로드에게 맡기지 말 것
로그인된 계정으로 동작하므로 **구매·결제·글 발행·설정 변경**은 시키지 말고 직접 하는 게 안전하다.
수집(읽기)까지만 맡기는 게 적절하다.
