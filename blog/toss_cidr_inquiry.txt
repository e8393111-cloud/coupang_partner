[제목] 출발지 IP 등록 시 CIDR 대역이 입력되지 않습니다

안녕하세요. 쉐어링크 Open API 연동을 준비 중인 크리에이터입니다.

어드민 > API 연동 > 출발지 IP 등록에서 CIDR 대역을 입력하면
"올바른 IP 주소 형식이 아니에요" 메시지와 함께 추가가 되지 않습니다.

- 입력한 값: 160.79.104.0/21
- 문서에 있는 예시 형식 그대로인 203.0.113.0/24 도 동일하게 거부됩니다.

공식 문서 「연동 시작하기」(sharelink-docs.toss.im/guide/open-api/auth.md)
출발지 IP 항목에는 표기 방식이 아래와 같이 안내되어 있습니다.

  "단일 IP 또는 CIDR 대역 (예: 203.0.113.10, 203.0.113.0/24)"

문서 안내와 실제 화면 동작이 달라 문의드립니다.
CIDR 대역 등록이 지원되는 것이 맞다면 입력 방법을 알려주시고,
현재 단일 IP만 가능한 상태라면 대역 등록 계획이 있는지 알고 싶습니다.

[등록하려는 대역]
  160.79.104.0/21   (Anthropic, PBC 소유 대역 / RDAP 조회 확인)

호출은 클라우드 환경에서 이루어지며, 출발지 IP가 이 대역 안에서
호출마다 바뀝니다. 대역이 2,048개라 단일 IP 10개로는 등록이 불가능합니다.

대역 등록이 어렵다면 /24 단위 8개(160.79.104.0/24 ~ 160.79.111.0/24)로
나누어 등록하는 것도 가능한지 함께 확인 부탁드립니다.

감사합니다.
