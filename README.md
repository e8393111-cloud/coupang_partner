# coupang_partner

쿠팡 파트너스(제휴 마케팅) 수익화를 위한 **개인용 대시보드**.
숏폼 기반 트래픽 파이프라인을 매일 반복 실행하는 데 필요한 도구들을 한 파일에 모았습니다.

## 사용법

`index.html`을 브라우저에서 열기만 하면 됩니다. 설치·빌드·서버 필요 없음.
입력한 데이터는 브라우저 `localStorage`에 자동 저장되어 껐다 켜도 유지됩니다.

## 기능

- **🏠 대시보드** — 매일 루틴 체크(자정 자동 초기화), 이번 달 입금 예정액, 배포 미완료 영상 수
- **📋 실행 가이드** — 유튜브 요약을 따라 하기 쉬운 순서로 재구성한 플레이북
- **🎯 상품 선정** — 문제해결력·바이럴·스토리텔링·소싱난이도로 점수화, 훅 아이디어 자동 생성
- **📤 배포 트래커** — 영상 하나당 5개 플랫폼(릴스·쇼츠·틱톡·페북·스레드) OSMU 배포 상태 체크
- **⚖️ 공정위 문구** — 배치 위치/스타일별 표준 문구 생성 + 클릭 복사
- **💰 정산 계산기** — 판매액 → 수익(3% / 유튜브 6.7~7%) → 익익월 15일 입금일 자동 계산

데이터 백업은 하단의 **내보내기/가져오기**(JSON)로 가능합니다.
